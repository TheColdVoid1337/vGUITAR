# vGUITAR Note Trainer — руководство пользователя

**Версия:** 0.5.5 (alpha) · [Главная страница](../../README.md) · [English README](../../README.en.md)

## Запуск и обновление

Установите Python 3.9+ для Windows (с Tkinter) и запустите `RUN.bat` из корня проекта. Скрипт автоматически создаст `.venv` и установит `sounddevice`, если он отсутствует. Для обновления существующего клона:

```powershell
git pull origin main
.\RUN.bat
```

Если звук не воспроизводится, нажмите **⚙** в правой части верхней панели, выберите аудиоустройство и проверьте громкость и тестовую ноту. На Windows применяется PortAudio/WASAPI. Приложение работает локально; личный аккаунт не нужен.

## О программе

Кнопка **?** рядом с «Историей» открывает окно «О программе»: иконка, версия, краткая справка, имя разработчика и кликабельные ссылки на его GitHub-профиль и репозиторий. Верхнее системное меню убрано; кнопка **⚙** открывает настройки.

## Карта грифа

На экране представлены шесть струн: сверху 1-я (тонкая E), снизу 6-я (толстая E). Лад 0 — открытая струна, далее до 24-го. При стандартном строе открытые струны с шестой по первую: **E A D G B E**.

Счётчик **«Струны»** по умолчанию активирует струны подряд от шестой: 1 → 6-я; 2 → 6-я и 5-я; 3 → 6-я, 5-я и 4-я. Начиная с v0.5.4, **«Выбор…»** открывает шесть переключателей для произвольного выбора. Например, для тренировки только пятой струны оставьте одну галочку **5-я · A** и нажмите «Применить». После этого счётчик показывает 1, но реальная выбранная струна — **пятая**. Изменение счётчика возвращает последовательный выбор от шестой.

Настройка доступна в режимах **«Назвать»**, **«Найти»** и **«На слух»**; гаммы и геометрические формы по своей природе работают с собственными набором струн и нот.

## Стандартный цикл занятия

1. Выберите режим в выпадающем списке **«Режим»**, затем струны и верхнюю границу ладов.
2. Укажите количество вопросов (5–100) и время «Повторение» (в секундах).
3. Используйте предварительную карту для запоминания или сразу начни проверку.
4. В режиме «Назвать» выберите название ноты; в «Найти» — лад на указанной струне; в «На слух» — прослушайте звук.
5. После ответа переходите к следующему вопросу (в том числе клавишей **Space**).
6. После завершения используйте «История» для просмотра результатов или копирования JSON-отчёта.

**Esc** возвращает к подготовке. В режиме «Найти» программа указывает нужную струну; ответы на другой струне игнорируются. При тренировке по всему грифу с повторяющимися классами нот логика учитывает дубли.

## Режимы «Назвать», «Найти», «На слух»

- **«Назвать»**: программа показывает положение на струне, нужно выбрать название ноты. Доступны ряды и круговой вариант ответов.
- **«Найти»**: программа показывает название и струну; нужно выбрать соответствующий лад. Задание проверяет искомую ноту, а не скорость подсчёта от открытой струны.
- **«На слух»**: воспроизводится высота звука; её нужно показать на грифе. Повторное прослушивание ограничено тремя дополнительными попытками, одинаковые абсолютные MIDI-высоты не дублируются в пуле.

Для каждой из этих тренировок удобно чередовать **отдельную струну → соседние две → смешанный набор**. Рекомендуется сперва добиться устойчивой точности, а затем сокращать время реакции.

## «Гаммы»

Семь доступных звукорядов: мажор, натуральный минор, дорийский, фригийский, мажорная и минорная пентатоника, блюзовая гамма.

В переключателе «Вид» есть три разных упражнения:

| Вид | Смысл |
|---|---|
| **Аппликатуры** | Только ноты конкретного гитарного рисунка |
| **Весь звукоряд** | Все ноты выбранной гаммы на грифе до 24-го лада |
| **Участок ладов** | Ноты гаммы в выбранном диапазоне ладов; **это не именованная аппликатура** |

Для семиступенных гамм доступны **семь 3NPS-позиций** (по три ноты на струне). Для двух пентатоник и блюзовой — по **пять боксов**. В блюзовой гамме добавлена и выделена ♭5 (blue note). Автоматический выбор позиции переключает её между занятиями.

**Пример:** A minor pentatonic → «Аппликатуры» → Box 1. На шестой струне внутри классического бокса 5-й и 8-й лады; на третьей — 5-й и 7-й. Нота на G9 может относиться к гамме, но не к Box 1.

## «CAGED»

Выберите корневую ноту, форму C / A / G / E / D и вид: **«Аккорд»**, **«Мажорная гамма»** или **«Минорная гамма»**. В аккордовом режиме представлены традиционные подвижные мажорные формы; в гаммовом — карты гаммы, связанные с этими позициями. **Минорные карты не означают, что все пять исходных открытых мажорных аккордов превращаются в одинаково удобные минорные аккорды.**

## «Формы»

**Power chord:** выберите корень, струну корня (6/5/4) и вариант **R–5** или **R–5–8**. R — тоника, 5 — чистая квинта, 8 — октава. Например, G5 от шестой струны использует лад 3 на E и лад 5 на A (а в трёхнотном варианте ещё лад 5 на D).

**Трезвучия:** выберите мажор, минор или уменьшённое, группу **1–2–3**, **2–3–4**, **3–4–5** либо **4–5–6**, а затем основной вид или первое/второе обращение. Переключатель «Ноты / Ступени / Пальцы» помогает связывать расположение звуков с гармонической ролью. Предложенные пальцы — рекомендации, а не единственно возможный способ исполнения.

## Локальные данные и отчётность

Параметры строя, звука и занятий сохраняются в `vguitar/data/settings/`; результаты занятий — в `vguitar/data/results/`. При первом запуске после переноса кода существующие JSON-файлы копируются из прежних корневых `settings/` и `results/`; оригиналы остаются на месте. Эти каталоги не входят в Git. **История** позволяет выделить несколько запусков, посмотреть точность и время ответа, скопировать JSON для дальнейшего анализа. В новой конфигурации `selected_strings` хранит физические номера струн (например, `[5]`); `active_strings` оставлено для обратной совместимости.
