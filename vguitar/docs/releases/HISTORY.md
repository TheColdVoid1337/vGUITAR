## Получение конкретной версии

Исходный код каждой версии можно получить из [раздела тегов](https://github.com/TheColdVoid1337/vGUITAR/tags). Для работы с локальным клоном:

```powershell
git fetch --tags origin
git switch --detach v0.5.4
```

Команда переводит рабочую директорию к исходникам выбранного выпуска. Для возвращения к актуальной ветке:

```powershell
git switch main
git pull --ff-only origin main
```

Все перечисленные теги являются фиксированными точками истории; существующие теги не следует передвигать. [Релиз v0.5.4](https://github.com/TheColdVoid1337/vGUITAR/releases/tag/v0.5.4) включает исходный код и примечания к выпуску.
