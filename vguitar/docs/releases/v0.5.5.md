# vGUITAR Note Trainer v0.5.5

**23 октября 2026 · alpha · Windows / Python / Tkinter**

Выпуск v0.5.5 обновляет интерфейс, добавляет **Русский / English** и существенно расширяет визуальную настройку грифа. Это исходный код приложения, **не готовый Windows-инсталлятор**.

## Главное

- **Два языка.** При первом запуске без сохранённых настроек появляется выбор **ENGLISH** или **РУССКИЙ**. Позднее язык можно изменить во вкладке **⚙ → Язык**.
- **Чище основной интерфейс.** Единый выпадающий список режимов, закреплённые группы управления, история по иконке **📖**, окно **? О программе** с полной иконкой, версией и ссылками. Настройки стали компактнее, аудиотест и «Лог звука» перенесены во вкладку **Аудио**.
- **Четыре накладки грифа.** Оригинальная, Черное дерево (Ebony), Клён (Maple) и Палисандр (Rosewood); выбор кликом по превью без dropdown. Неактивная зона Ebony выделена более серым.
- **Натуральная текстура.** Включаемый отдельно Canvas-слой древесных волокон с кнопкой **Рандомизировать**. Случайный рисунок воспроизводится по сохранённому seed; для виртуальной Оригинальной накладки текстура недоступна.
- **Внешний вид струн.** Калибры 8–38, 9–42, 9–46, 10–46, 10–52, 11–48 и 12–56. Цветовые варианты: никелированная сталь, чистый никель, нержавеющая сталь, кобальтовый сплав.
- **Порожек.** Визуальная толщина **3–8 мм** с шагом **0,5 мм**; пластик, кость, TUSQ, графит, латунь или медь.
- **Ладовая проволока.** Ширины коронки 2.03, 2.28, 2.41, 2.54, 2.79, 2.99 мм и **SINTOMS 4.3mm**; цветовые варианты нейзильбер, нержавеющая сталь и EVO Gold.
- **Ладовые маркеры.** Настройка радиуса ползунком **2,5–7,5 px** с шагом **0,5 px**.
- **Надёжность настроек.** Предварительный просмотр до сохранения, «Отмена» возвращает значения; параметры сохраняются между запусками. Ранее выбранные ash/mahogany автоматически сопоставляются с Maple/Rosewood, старые результаты занятий не удаляются.
- **Код и структура.** Приложение, тесты, ресурсы и документация расположены в папке vguitar; корневой RUN.bat сохранён. Локальная история переехала в vguitar/data с копированием legacy JSON без удаления оригиналов.

**Важно:** материалы, калибры, миллиметры порожка и коронки **влияют только на графическое отображение**, не на физический звук, строй, MIDI или координаты нот.

## Музыкальные возможности

Режимы **Назвать / Найти / На слух**, включая произвольный выбор отдельных струн и вопросы до 24-го лада; семь гамм, 3NPS и пентатонические/блюзовые боксы; CAGED; power chords R–5 / R–5–8 и трезвучия с обращениями. Локальная история включает точность, время ответа и экспорт JSON.

## Установка

Необходимы Windows, Python 3.9+ с Tkinter и доступное устройство звука. Интернет может понадобиться при первой установке зависимости sounddevice. Клонируйте исходники, запустите **RUN.bat**; при наличии клона — обновите его через Git fast-forward.

Для фиксации исходников именно этого релиза используйте тег **v0.5.5** после его публикации. Готового Windows-инсталлятора и CI нет.

## Проверки и ограничения

Unit-тесты и GUI smoke-сценарии должны проходить локально на Windows **до создания тега и публикации Release**. GitHub Actions в этом репозитории не настроены; Windows-проверка звука и отображения на конкретном компьютере остаётся отдельным ручным этапом.

Статус **alpha**: некоторые музыкальные формы требуют стандартных интервалов между струнами. Аппликатуры пальцев — рекомендации. Готового установщика нет; WASAPI зависит от оборудования и драйверов Windows.
