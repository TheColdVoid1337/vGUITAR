**Версия 0.5.4 (alpha)** · Python / Tkinter · офлайн после установки зависимостей · [MIT](LICENSE)

**vGUITAR** помогает перестать высчитывать ноты от открытой струны и научиться быстро узнавать позиции на грифе, находить корни аккордов и понимать интервалы. Это настольная программа для занятий на настоящей гитаре или без неё — не приложение для iPhone. Иконка оформлена в стиле мобильного приложения.

## Возможности

- **Шесть режимов:** «Назвать», «Найти», «На слух», «Гаммы», «CAGED», «Формы».
- **Любые струны по отдельности.** Кнопка **«Выбор…»** позволяет оставить только 5-ю, 4-ю или любую комбинацию. Счётчик **«Струны»** по-прежнему быстро включает 6-ю, затем 5-ю и т. д.
- **Гриф 0–24:** обозначения нот на английском и русском, позиции, разметка ладов; несколько оформлений древесины.
- **Семь гамм:** мажор, натуральный минор, дорийский, фригийский, мажорная и минорная пентатоника, блюзовая.
- **Настоящие аппликатуры:** семь 3NPS-позиций для семиступенных гамм; пять пентатонических и блюзовых боксов (включая ♭5); отдельно полный звукоряд и диапазон ладов.
- **CAGED:** пять мажорных аккордовых форм, а также пять привязанных к ним схем мажорной и натуральной минорной гаммы.
- **Аккордовые формы:** power chords (R–5 / R–5–8, корень на 6-й, 5-й или 4-й струне), мажорные/минорные/уменьшённые трезвучия и три обращения на четырёх группах струн.
- **Звуковая обратная связь:** синтезированное звучание струны, задания «На слух», настройка аудиоустройства и строя.
- **Локальная статистика:** правильность, время ответов, история занятий и JSON-экспорт для дальнейшего анализа.

## Начать заниматься

Нужны **Windows, Python 3.9+**, поддержка Tkinter и аудиовыход. Скачай код с GitHub или клонируй репозиторий:

```powershell
git clone https://github.com/TheColdVoid1337/vGUITAR.git
cd vGUITAR
.\RUN.bat
```

При первом запуске `RUN.bat` создаст `.venv` и при необходимости установит `sounddevice` из `requirements.txt`. Для первоначальной установки пакетов понадобится интернет. Затем занятия работают локально, без регистрации и облачного аккаунта.

### Три коротких упражнения

**Выучить пятую струну:** режим «Назвать» → «Выбор…» → только **5-я (A)** → лады **7** → 30–50 вопросов. Для обратного направления переключись на «Найти».

**Научиться узнавать корни:** выбери 6-ю и 5-ю струны и диапазон 0–7. Вспомни, что G на 6-й струне, 3-м ладу даёт корень G5, а C на 5-й, 3-м ладу — C5. Затем проверь себя в «Формы» → «Power chord».

**Разобрать пентатонику:** «Гаммы» → «Минорная пентатоника» → тональность A → «Аппликатуры» → «Box 1». В отличие от «Участок ладов», бокс включает только ноты конкретной аппликатуры.

## Режимы

| Режим | Задача |
|---|---|
| **Назвать** | Увидеть струну и лад, назвать ноту |
| **Найти** | Получить название ноты, найти её на указанной струне |
| **На слух** | Услышать звук и определить позицию (повторы ограничены) |
| **Гаммы** | Учить интервалы и геометрию гамм по аппликатурам или всему грифу |
| **CAGED** | Связать корень, форму аккорда и карты мажора/минора |
| **Формы** | Выучить power chords, трезвучия и обращения |

При необходимости сначала запусти «Повторение» на заданное время, затем переходи к проверке. **Space** — следующий вопрос после ответа; **Esc** — вернуться к подготовке.

## Результаты, настройки и звук

Настройки хранятся локально в `settings/`, результаты — в `results/` рядом с программой. В меню **«История»** можно открыть прошлые тесты и скопировать JSON-отчёт. Экспорт содержит настройки упражнения (в том числе точный набор струн), результаты и время каждого ответа.

В меню **«Настройки → Строй и звук…»** доступны стандартные, пониженные, Drop/Open и пользовательский строи. Аудиобэкенд на Windows использует `sounddevice` / PortAudio с приоритетом WASAPI. Некоторые геометрические аппликатуры требуют стандартного интервального строя: при несовместимой настройке программа не должна выдавать неверную «стандартную» форму.

## Разработка

```powershell
python -m unittest discover -s tests -v
python -m py_compile vguitar_notes.py
```

Графические smoke-тесты находятся в `tests/gui_*.py` и требуют доступного дисплея (на Linux — Xvfb). **GitHub Actions отключены**: локальная проверка остаётся обязательной. Документация обновляется только по явной команде `#syncdocs`, а оперативные события фиксируются в `docs/dev/events.json`.
