# vGUITAR Note Trainer v0.5.4

Выпуск v0.5.4 расширяет упражнения на грифе возможностью выбирать отдельные струны. Версия находится на этапе **alpha**.

## Главное в v0.5.4

**Выбор любой струны отдельно.** Раньше настройка «1 струна» всегда означала только шестую. Теперь рядом со счётчиком есть **«Выбор…»**: можно оставить одну пятую, четвёртую или любую комбинацию струн. Выбор применяется к режимам «Назвать», «Найти» и «На слух», сохраняется между запусками и присутствует в отчётах (`selected_strings`). Старый счётчик по-прежнему работает как быстрый выбор подряд от шестой.

**Пример использования:** режим «Назвать» → «Выбор…» → нужные струны → диапазон ладов → количество вопросов. Обратное упражнение доступно в режиме «Найти».

## Возможности, накопленные к этому релизу

- Назвать/найти/услышать ноту; настраиваемые строи и звук, визуальная карта 0–24 ладов.
- Семь гамм: major, natural minor, Dorian, Phrygian, две пентатоники и blues.
- Семь 3NPS-позиций для семиступенных гамм и пять боксов для пентатоник/блюзовой гаммы; полный гриф и произвольные окна изучения **отделены** от настоящих аппликатур.
- CAGED-формы аккордов и связанные с ними карты мажорной/минорной гаммы.
- Power chords R–5/R–5–8, трезвучия мажор/минор/dim, три обращения, четыре группы струн.
- Сохранение параметров и результата каждого занятия, история и JSON-экспорт.

## Установка и обновление

Требования: Windows, Python 3.9+ с Tkinter, доступное аудиоустройство; интернет при первоначальной установке `sounddevice`.

```powershell
git clone https://github.com/TheColdVoid1337/vGUITAR.git
cd vGUITAR
.\RUN.bat
```

Если клон уже существует:

```powershell
git pull origin main
.\RUN.bat
```

## Известные ограничения

- Версия **alpha**: некоторые CAGED/3NPS/боксовые формы рассчитаны на стандартные интервалы между струнами и не подменяются ошибочными аппликатурами при несовместимом строе.
- Проверки выполняются локально; GitHub Actions не запускаются. GUI/аудио на конкретных конфигурациях Windows требуют ручного подтверждения.
- Приложение выпускается в виде исходного кода для Windows; готового установщика нет.
